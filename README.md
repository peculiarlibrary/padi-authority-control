## 🔄 Deterministic Knowledge Flow
Data within the Sovereign Bureau is orchestrated through a multi-stage validation gate to ensure **Constraint Sovereignty**.

1. **Ingestion**: Raw YAML artifacts (Skills, Logs, or Authority Records) are introduced to the `data/` directory.
2. **Semantic Classification**: The `sovereign_audit.sh` agent identifies the correct **LinkML** target class based on path and prefix (e.g., `data/log_` vs `data/skill_`).
3. **Logic Gate**: Artifacts are validated against the **PADI v3.0 Schema**. If a violation is found, the sync is aborted.
4. **Ledger Update**: Validated nodes are committed and synchronized with the remote authority root via `sync_bureau.sh`.
